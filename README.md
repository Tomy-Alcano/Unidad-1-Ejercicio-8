# Unidad-1-Ejercicio-8
Programacion 3 Unidad 1 Ejercicio 8
Ejercicio 8 — Selector de configuración de pantalla
Este ejercicio trabaja específicamente con JComboBox y JRadioButton en un contexto diferente al de un formulario de datos personales, para que practiques estos componentes en distintos escenarios de uso.

Creá una ventana que simule un panel de configuración de pantalla con los siguientes elementos:

Una etiqueta con el texto "Configuración de pantalla" como título
Una etiqueta y un JComboBox para seleccionar la Resolución, con las opciones: 1280x720, 1920x1080, 2560x1440, 3840x2160
Una etiqueta y un JComboBox para seleccionar la Frecuencia de actualización, con las opciones: 60 Hz, 75 Hz, 120 Hz, 144 Hz, 240 Hz
Una etiqueta y tres JRadioButton agrupados para seleccionar el Modo de color: Estándar, Cinematográfico y Juegos
Un JCheckBox con el texto "Activar modo nocturno"
Un JCheckBox con el texto "Aplicar cambios automáticamente"
Un botón con el texto "Aplicar"
Un botón con el texto "Restaurar valores predeterminados"
💡 Tip: cuando hay múltiples JCheckBox en un formulario, cada uno funciona de forma independiente: no necesitan estar agrupados como los JRadioButton.
